# Public demo fixtures

Every name, course, place, date, and roster entry in this directory is fictional and created only to demonstrate Snap2Cal. The fixtures do not represent a real person, school, employer, chat, appointment, timetable, or roster.

`demo-data.json` is the single structured source used by `npm run capture:demo`. The script renders local HTML/CSS to PNG inputs under `public/demo/` and then captures application states under `docs/images/`. It does not download images, logos, fonts, portraits, or other media from the internet.

Do not replace these fixtures with a real screenshot or minimally redacted user image. Add a new synthetic example when a reproduction is needed.
