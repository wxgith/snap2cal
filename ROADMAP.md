# Roadmap

This document records discussion directions, not commitments, dates, or assigned work. The v1.0 preparation phase is feature-frozen.

## Release stability

- Connect the confirmed public `snap2cal` repository after its owner and default branch are known.
- Exercise CI, Pages, and Draft Release workflows in the eventual GitHub repository.
- Expand deterministic regression fixtures for the four existing modes.
- Continue bundle, runtime-network, privacy, and accessibility audits.

## Browser coverage

- Broaden real OCR Worker/WASM validation beyond Chromium where maintainable.
- Track browser changes affecting clipboard image paste, downloads, Canvas, workers, or WebAssembly.
- Add device-level manual checks without claiming universal browser support.

## Recognition research

Possible future discussions include additional OCR languages, borderless tables, more varied timetable geometry, and more varied roster layouts. Any work must preserve explicit user confirmation, local processing, evidence mapping, and deterministic tests.

## Input formats and calendars

PDF, Excel, CSV, holiday adjustment, more calendar interoperability checks, and additional date language may be discussed after v1.0. They are not implemented or scheduled. Accounts, cloud sync, payroll, attendance, and legal compliance analysis remain outside the current product boundary.
