# Suggested GitHub labels

These labels are recommendations only. This task does not create them remotely, and release-note configuration does not assume they already exist.

| Label              | Color    | Purpose                                                    |
| ------------------ | -------- | ---------------------------------------------------------- |
| `feature`          | `1D76DB` | Existing-scope user-facing capability                      |
| `bug`              | `D73A4A` | Confirmed incorrect behavior                               |
| `documentation`    | `0075CA` | Documentation-only change                                  |
| `performance`      | `5319E7` | Measured performance or bundle change                      |
| `accessibility`    | `0E8A16` | Keyboard, semantics, contrast, or assistive technology     |
| `security`         | `B60205` | Security maintenance; vulnerability details remain private |
| `dependencies`     | `0366D6` | Dependency or Action update                                |
| `internal`         | `6E7781` | Refactor, CI, test, or release infrastructure              |
| `ocr`              | `FBCA04` | Local OCR or image evidence                                |
| `timetable`        | `C2E0C6` | Timetable mode                                             |
| `shift-roster`     | `F9D0C4` | Shift-roster mode                                          |
| `privacy`          | `BFD4F2` | Data handling or public fixture review                     |
| `good first issue` | `7057FF` | Narrow contributor-friendly task                           |
| `help wanted`      | `008672` | Maintainer welcomes assistance                             |
| `skip-changelog`   | `EDEDED` | Exclude from generated release notes                       |
| `duplicate`        | `CFD3D7` | Existing report covers the issue                           |
| `invalid`          | `E4E669` | Not actionable or outside repository rules                 |
| `question`         | `D876E3` | Usage or clarification, excluded from release notes        |

Review colors and descriptions in the repository UI before creation. Do not assign security reports to a public label when that would expose vulnerability details.
