# 课程表导入

本页保留为旧链接入口。第四阶段课程表功能现已从简化 OCR 坐标归并升级为完整网格工作流，请阅读：

- [课程表二维架构](schedule-table-architecture.md)
- [网格检测与人工校正](grid-detection.md)
- [课程周次规则](course-week-patterns.md)
- [课程 occurrence 与 ICS](course-occurrences.md)

当前用户入口只处理单张清晰矩形网格课程表截图。流程为本地 OCR、真实网格检测、人工校正、星期和时间映射、课程格编辑/纵向合并、课程模板、具体 occurrence 和批量 ICS。旧的 `|` 分隔文本课程表解析器保留为内部兼容测试代码，不再是第四阶段主界面，也不承担图片二维识别。

图片、OCR、网格、课程和排除项只在当前浏览器页面内存中处理，不上传、不持久化。当前不支持排班表、PDF/Excel/CSV、多图、无边框或透视课表、横跨星期、多级表头、校历例外、调停课和 `RRULE`。
