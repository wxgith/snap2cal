# 班次定义与代码映射

## 精确代码

班次代码先执行 Unicode NFKC、首尾空白清理、连续空白折叠和大写规范化，再按主代码或别名精确匹配。除此之外不做模糊匹配、编辑距离、前缀推断或自动纠错。`-`、`/`、`0`、`OFF` 等非空值都作为真实代码扫描；未映射时阻止导出，不会当作空白。

每个代码或别名只能归属一个定义。别名冲突会在定义和 assignment 上产生错误。代码目录显示原始形式、出现次数、人员数、首末日期、平均 OCR 置信度与示例来源格。OCR、字段和候选置信度仍是不同概念。

## 定义类型

- `timed`：需要有效 `HH:mm` 开始和结束时间；结束早于开始时还必须明确确认跨午夜。
- `all-day`：生成具体排班日的全天事件，不保留定时时间。
- `skip`：保留 assignment 和原图证据，但不生成 occurrence 或 `VEVENT`。

定义名称不能为空，所有定义都必须由用户确认。开始等于结束被视为不支持的 24 小时班次；结束晚于开始却勾选跨午夜会超过 24 小时，同样拒绝。一个格内出现多个代码或多段班不会自动拆分，只进入人工复核。地点、说明、提醒和别名均来自用户输入，不进行业务推断。
