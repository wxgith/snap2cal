# Snap2Cal v1.0.0-rc.1

## Purpose

This is the first public release candidate for Snap2Cal 1.0. It is for focused review and is not the final stable release.

## Included modes

- Text event
- Image event
- Timetable
- Shift roster

## What reviewers should test

- Chinese date and time review
- ICS import
- Browser-local OCR
- Source-image evidence
- Timetable grid correction
- Teaching-week expansion
- Shift-code mapping
- Cross-midnight shifts
- Individual and team roster export

Use synthetic data and review every generated event before importing it.

## Privacy

- No backend
- No cloud OCR
- No persistence of user input
- No analytics or remote error reporting
- Same-origin runtime assets

GitHub Pages supplies static hosting and may process ordinary web-server metadata under GitHub's terms. Snap2Cal does not add tracking code.

## Known limitations

- OCR, date/time parsing, evidence mapping, and grid recognition can be wrong and require review.
- Image OCR accepts one PNG, JPEG, or WebP image at a time; handwriting and complex layouts may be unreliable.
- PDF, Excel, CSV, batch images, recurrence rules, accounts, and cloud synchronization are unsupported.
- Borderless, merged, or heavily decorated timetable and roster layouts may require substantial correction or may be unsuitable.
- A cell cannot represent multiple shifts, and rosters do not make payroll, attendance, labor-law, or compliance decisions.

## Install and test

The live candidate is served at <https://wxgith.github.io/snap2cal/>.

For local development:

```bash
npm ci
npm run prepare:ocr
npm run dev
```

For the static archive, verify `snap2cal-v1.0.0-rc.1-SHA256SUMS.txt`, extract `snap2cal-v1.0.0-rc.1-static-site.zip`, and serve the extracted root over HTTP. Do not use `file://`; ES modules, the OCR Worker, WASM, and language files require HTTP.

```bash
sha256sum -c snap2cal-v1.0.0-rc.1-SHA256SUMS.txt
unzip snap2cal-v1.0.0-rc.1-static-site.zip
cd snap2cal-v1.0.0-rc.1
npx serve .
```

## Reporting problems

- General issues: <https://github.com/wxgith/snap2cal/issues>
- OCR problem form: <https://github.com/wxgith/snap2cal/issues/new?template=ocr-problem.yml>
- Security policy: <https://github.com/wxgith/snap2cal/security/policy>

Issues and attachments are public. Use newly created synthetic examples whenever possible and never post real schedules, rosters, contact details, credentials, or vulnerability details. GitHub Private Vulnerability Reporting is not enabled and no security email address is published; follow the security policy to request a private channel without disclosing details publicly.
