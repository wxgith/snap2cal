# 共享二维网格检测

## 自然坐标

图片经现有规范化流程解码方向并生成 PNG。`TableGrid.imageWidth/imageHeight`、`GridLine.position`、`GridCell.bbox` 和 OCR 框都使用该图片的自然坐标。SVG 只用相同宽高作为 `viewBox` 做响应式显示，CSS 缩放值不会写回模型。

## 投影算法

`ProjectionGridDetector` 不依赖 React 或 Canvas。Canvas 仅在边界层把规范化 Blob 转为 `ImageData`；像素算法本身是可测试纯函数：

1. RGBA 按亮度转换为深色像素掩码。
2. 分别计算每个 x 的纵向深色覆盖率和每个 y 的横向深色覆盖率。
3. 按相对峰值与最低覆盖率筛选连续响应区间。
4. 用覆盖率加权得到粗线中心，并合并距离过近的候选。
5. 根据线连续性、交点覆盖率、间距合理性和矩形数量计算总体置信度。
6. 校验线数量、图片范围、重复位置和最小单元格尺寸。

无法形成完整网格时返回 `GRID_NOT_DETECTED`；置信度低于阈值时返回 `GRID_LOW_CONFIDENCE`。检测失败不终止页面，用户仍可手工添加网格线。所有自动结果必须人工确认。

## 人工编辑

覆盖层显示水平线、垂直线和单元格。线可以拖动或用方向键每次移动 1 个自然像素，按 Shift 时移动 10 像素；工具栏也提供明确的 `-10/-1/+1/+10` 按钮。可添加、删除、锁定、解锁或恢复自动检测。线不能越出图片、跨过相邻线或形成小于最小尺寸的单元格。移动自动线后 `origin` 变为 `manual`，但稳定 line id 保留。

## OCR 分配

`assignOcrBlocksToGridCells` 只读取 `OcrDocument` 和 `TableGrid`。忽略块不参与；中心点所在格优先，同时计算块与各格的面积重叠。中心点与最大重叠不一致、或前两个重叠过于接近时提示歧义。无法达到最低重叠的块进入未分配列表，不复制到多个格。

格内块按 y、OCR 行、x 和原始顺序稳定排序。不同视觉行使用换行；相邻中文不无条件加空格，连续拉丁/数字词之间保留空格。`originalText` 使用 OCR 初始值，`text` 使用校正值。

当前不做透视校正、去噪增强、旋转检测、通用轮廓分析、无边框卡片检测或大型计算机视觉依赖。

## 课程表与排班表复用

项目只维护一套 `ProjectionGridDetector`、`TableGrid`、网格编辑函数和 OCR 单元格分配逻辑。课程表在共享网格上解释“星期 × 时段”，排班表通过独立 `shift-roster` 层解释“人员 × 日期”；排班表不会复制像素算法，也不会使用 `CourseTemplate`。

两个模式都在首次进入时延迟加载，网格覆盖层使用相同自然坐标和键盘操作。聚焦一条网格线会同步选中该线，方向键移动 1 像素，Shift 加方向键移动 10 像素。任何网格移动、新增、删除或恢复都会重新分配 OCR 块，并使对应模式的下游语义确认与 occurrence 状态失效。
