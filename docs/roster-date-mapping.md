# 排班日期映射

## 表头与配置

用户必须确认日期标题行、人员姓名列、人员行范围和日期列范围；星期标题行可选。自动检测只提供可见建议，不直接确认。最多接受 31 个日期列。

支持以下日期标题：

- 完整日期：`2026-09-01`、`2026/9/1`、`2026年9月1日`，不依赖额外配置。
- 月日：`9-1`、`9/1`、`9月1日`，必须提供用户确认的排班年份。
- 日号：`1`、`1日`，必须同时提供用户确认的排班年份和月份。

缺少必需年份或月份会产生阻止性错误；实现不读取系统当前年月，也不会从文件名、人员、相邻业务语义中猜测。人工改过的日期格不会被年月配置静默覆盖。

## 校验

日期使用真实公历校验，包括每月天数和闰年。相同规范日期映射到多列时产生重复错误；后一日期不晚于前一日期时产生乱序错误。存在星期行时会把中文或英文星期与具体日期核对，不一致时给出用户可见警告。

完整日期和月日可以明确表达跨月。跨年必须在表头中写完整年份或由用户修正具体日期；例如同一年配置下的 `12/31, 1/1` 会被标为乱序，不会静默推断下一年。只含日号的表头限定在用户确认的单个月份，不自动跨月。
